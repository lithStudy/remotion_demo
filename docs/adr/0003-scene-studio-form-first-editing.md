# 分镜工作台以表单/选择为默认编辑面

分镜工作台（Scene Studio）默认用表单与下拉选择编辑分镜脚本，不以手写 JSON 为默认路径。脚本编辑两阶段：场景内扁平口播表（一行一条 content，分组头改模板/归类，默认可读点按编辑）完成 item 归类与模板选择；再钻取进入 param 页（局部参数重生只在此页）。改模板立即清空 param。导航仅场景列表，不列 item 树。口播可在相邻 item 间按时间序移动（→上一接末尾、→下一接开头；源移空则删 item）。param 用通用一层列表/对象表单；`param_array_sync_content` 与 content 条数锁定。

**Status:** accepted

## Considered Options

- 结构选择 + 文案可输 / 几乎全点选摘取 / 表单默认 + Raw JSON 逃生口 → 选前者，避免手机改 JSON，同时保留措辞手输。
- 移动后自动重生 param / 手动按钮 / 连模板一起重选 → 选手动且只刷 param，避免覆盖用户刚定的模板。
- 空 item 保留 / 确认删除 / 禁止移走最后一条 / 自动删除 → 选自动删除，避免幽灵 item。
